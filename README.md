Este repositorio contiene ejercicios de Análisis de Datos con Python realizados con diferentes datasets obtenidos de varios recursos en linea.
El objetivo es practicar con datasets y ejercicios reales, generar una documentación propia que pueda consultar mas adelante y aprender a utilizar la 
la herramienta de IA Gemini incluida en Colab para la creación de gráficos.
